# blogfolio

Personal blog and portfolio site (maik-hasler.de), English-language content.
Solo-maintained.

## Tech Stack

Astro 6 (static output, Node adapter), Tailwind CSS 4, MDX. Content is an
Astro content collection at `src/content/blog` (blog posts); the surrounding
UI is English too. Deployed as a Docker image published to GHCR on version
tags (`.github/workflows/publish.yaml`).

## Design

The site is a personal, editorial portfolio with one custom Magic: The
Gathering card as its visual signature. The rest of the homepage should feel
like Maik's own notes, not a row of card-shaped UI. `docs/design.md` is the
source of truth for the visual direction and tokens (`src/styles/global.css`).
Fonts are self-hosted OFL files in `public/fonts/`. All artwork is original;
the Open Graph image is generated by `npm run og` (`scripts/og-image.mjs`,
needs Playwright). Never add Wizards of the Coast assets or fonts.

## Conventions

- Everything is English: UI strings, code identifiers, comments, docs.
- Blog posts come from `src/lib/posts.ts` (`getPublishedPosts()`,
  `postUrl()`); never call `getCollection('blog')` elsewhere.
- Astro scoped styles beat Tailwind utilities (unlayered vs. `@layer`), so a
  component's scoped rule wins over a `class` passed in from outside. Put
  tone variants on `data-tone` and select on that.
- `npm run check` must stay green; CI (`.github/workflows/ci.yaml`) and the
  Docker build both run it.

## Development Setup

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run check    # astro check - typecheck + diagnostics
npm run og       # regenerate public/og-default.png (needs Playwright)
```

## Claude Code Configuration

- **Skills** - `.claude/skills/frontend-design/` (vendored from
  `anthropics/skills`, Apache-2.0, `LICENSE` alongside it) pushes visual
  changes toward a deliberate, non-generic design direction - typography,
  color theming, motion, spatial composition - instead of generic
  AI-layout defaults; load it before visual/layout changes to components
  or pages.
- **Hooks** - `.claude/hooks/pre-stop-verify.sh` (`Stop` hook) runs
  `npm run check` once before ending a turn if `src/` or `astro.config.ts`
  changed, blocking only on an actual failure (capped at 2 blocks per
  session so it fails open rather than risk a loop).
- **Plugins** - `typescript-lsp` is enabled in `.claude/settings.json`.
